# Hugo Blog Project - Claude Code Configuration

## Skills Management

**IMPORTANT**: This project uses **global skills only**. Do NOT create project-level skills in `.claude/skills/`.

### Global Skills Location
All skills are managed in: `~/.claude/skills/`

### Available Skills for This Project
- `write-tech-blog`: 创建高质量技术博客文章
- `qiaomu-paper-interpreter`: 学术论文解读
- `baoyu-*`: 各类内容生成和发布工具
- `mermaid-visualizer`: 图表生成
- 其他通用 skills 请参考全局 skills 列表

### Why Global Skills?
1. **可复用性**: Skills 可在多个项目间共享
2. **版本管理**: 避免项目仓库污染
3. **统一维护**: 集中管理和更新
4. **清洁仓库**: 保持项目目录结构简洁

## Project-Specific Instructions

### Blog Content Creation
- 使用 `write-tech-blog` skill 创建技术文章
- 文章路径: `content/posts/`
- 图片路径: `static/images/plots/`
- 支持 LaTeX 数学公式（MathJax 渲染）
- 支持 Mermaid 图表

### Hugo Configuration
- 主题: PaperMod
- 基础 URL: https://blog.example.com
- 语言: 中文 (zh-CN)

### LaTeX/MathJax Notes
- 避免使用与 Markdown 冲突的符号 (*, |, \)
- 如果公式渲染问题持续 2-3 次修复后仍未解决，重写该部分而不是继续修补

### Git Workflow
- 主分支: `main`
- 提交前确保 Hugo 构建成功: `hugo --minify`
- 图片文件应该被 git 追踪

## File Structure
```
blog/
├── .claude/
│   └── CLAUDE.md          # 本文件（项目配置）
├── content/
│   └── posts/             # 博客文章
├── static/
│   └── images/
│       └── plots/         # 生成的图表
├── scripts/               # 辅助脚本
└── config.yml             # Hugo 配置
```

## DO NOT
- ❌ 在 `.claude/skills/` 创建项目级别的 skills
- ❌ 复制全局 skills 到项目目录
- ❌ 提交临时生成的 HTML 文件到 git
