### LaTeX/MathJax Notes (⚠️ CRITICAL)

**Hugo + MathJax 公式渲染要点**（根据 2026-02-22 血泪教训）：

1. **下划线必须转义**: `$R^{ho}_{
u
u}` → `$R^{\rho}\_{\nu\nu}`
   - Hugo 的 Goldmark 解析器会优先把 `_` 当作 Markdown 斜体标记
   - 所有下标中的 `_` 必须用 `\_` 转义

2. **避免使用 `\boldsymbol`**: MathJax 不支持，使用 `\mathbf` 代替

3. **星号上标**: 使用 `^{\ast}` 而非 `^*`

4. **参考文档**: 详见 `~/.claude/skills/write-tech-blog/references/LATEX-MATH.md`

**质量检查流程**（写完后必须执行）：
```bash

python3 scripts/check_math_formulas.py content/posts/文章.md

# 2. 完整发布前检查

# 3. 通过后才构建
hugo --minify
```
